## HOW TO DEPLOY (Safe & Free) — Step by Step

### STEP 1 — Upload these files to GitHub
1. Go to github.com → log in
2. Click your vibewrite repository
3. Click "uploading an existing file"
4. Drag ALL files from this folder into the upload box
5. Click green "Commit changes" button
6. If GitHub shows a security warning → click "Cancel" (key is no longer in the code!)

---

### STEP 2 — Deploy on Vercel + Add Your API Key Safely
1. Go to vercel.com
2. Click "Sign Up" → "Continue with GitHub"
3. Click "Add New Project"
4. Find "vibewrite" → click "Import"
5. IMPORTANT: Before clicking Deploy, find "Environment Variables" section
6. Add this exactly:
   - NAME:  REACT_APP_ANTHROPIC_API_KEY
   - VALUE: paste your API key here (the sk-ant-api03-... code)
7. Now click "Deploy"
8. Wait 2 minutes → your site is LIVE! 🎉

Your API key is now hidden safely inside Vercel.
Nobody can see it. Not even GitHub.
